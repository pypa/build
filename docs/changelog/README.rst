#####################
 Changelog Fragments
#####################

This directory contains fragments for the next release. See the `contribution guide
<https://build.pypa.io/en/latest/development/contributing.html#changelog-fragments>`_ for filenames, fragment types,
examples, and previewing the changelog.

The `release guide <https://build.pypa.io/en/latest/development/release.html>`_ describes how fragments are collected
and how they determine the version bump.
